# my-load-planner

3D-планировщик загрузки грузовых автомобилей — автономное веб-приложение (SPA) на React 18 + TypeScript + Three.js.

## Возможности

- 🚚 **Управление автомобилями**: готовые пресеты (ГАЗель, Бычок, ЗИЛ, КамАЗ, Фура) + создание собственных кузовов.
- 📦 **Управление грузами**: таблица, добавление/удаление, CSV-импорт и экспорт, пресеты европаллет и финпаллет.
- 🧮 **3D-бинпакинг**: учёт габаритов, веса, вращения грузов и штабелирования (max. высота штабеля настраивается).
- 📊 **Три варианта раскладки**: вдоль, поперёк, смешанный — с переключением вкладок и метриками.
- 📈 **Подсказки**: автоматический подбор оптимальных решений (в т.ч. обновляется после ручных перемещений грузов).
- 🎨 **3D-визуализация**: Three.js (@react-three/fiber, @react-three/drei), прозрачный кузов, тултипы, орбитальный контрол; 2D-вид с пошаговым просмотром слоёв.
- 🖐 **Ручное редактирование**: перетаскивание грузов мышью в 2D/3D, правка координат и поворота, перемещение между слоями (↑/↓), автоматическое штабелирование (S).
- 📄 **Отчёты**: PDF (react-pdf) с параметрами авто, списком грузов с группировкой по слоям, 2D-схемами и инструкцией для грузчиков; экспорт 3D-сцены и 2D-схемы в PNG.
- 🔄 **Единицы измерения**: переключатель мм/см/м и кг/т без пересборки.
- ⚙️ **Свёрнутые секции** на левой панели для удобной навигации по «Грузам», «Автомобилю» и «Управлению».
- 💾 **Сохранение**: все данные (пресеты, грузы, раскладки, сессии) хранятся в localStorage.
- 🌗 **Тёмная/светлая тема**.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на **http://localhost:5173** (порт Vite по умолчанию).

## Сборка для продакшена

```bash
npm run build
npm run preview
```

Готовый статический бандл появится в папке `dist/` — его можно разместить на любом статическом хостинге (Netlify, Vercel, GitHub Pages).

## Структура проекта

```
src/
├── components/
│   ├── Layout/           # Header, Footer
│   ├── VehicleSelector/  # выбор и создание авто
│   ├── CargoTable/       # таблица грузов + CSV
│   ├── VariantTabs/      # вкладки вариантов
│   ├── MetricsPanel/     # карточки метрик
│   ├── Scene3D/          # 3D-сцена, контейнер, грузы, drag-контролы, редактор координат
│   ├── Report/           # кнопка отчёта
│   └── Settings/         # модалки настроек и сессий, переключатель темы
├── store/                # Zustand store
├── lib/
│   ├── packer/           # алгоритм упаковки, пресеты, типы
│   ├── export/           # PDF и PNG экспорт
│   └── csv/              # импорт/экспорт CSV
├── types/                # общие типы
└── utils/                # помощники
```
