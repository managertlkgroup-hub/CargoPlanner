# my-load-planner

3D-планировщик загрузки грузовых автомобилей — автономное веб-приложение (SPA) на React 18 + TypeScript + Three.js.

## Возможности

- 🚚 **Управление автомобилями**: готовые пресеты (ГАЗель, Бычок, ЗИЛ, КамАЗ, Фура) + создание собственных кузовов.
- 📦 **Управление грузами**: таблица, добавление/удаление, CSV-импорт и экспорт, пресеты европаллет и финпаллет.
- 🧮 **3D-бинпакинг**: учёт габаритов, веса, вращения грузов и штабелирования (max. высота штабеля настраивается).
- ➗ **Зазоры**: настройка отступа от стенок кузова со всех сторон (по умолчанию 5 см) — уменьшает доступное пространство и позволяет учесть толщину «пальца»/прокладок.
- 🧩 **Разные типы грузов одновременно**: прямоугольные грузы и цилиндры (бочки, рулоны) упаковываются в одной раскладке; задаётся ориентация цилиндров (горизонтально/вертикально).
- 🌐 **Переключатель языка РУС/ENG**: выбор языка интерфейса в шапке, выбор сохраняется в localStorage.
- 📊 **Три варианта раскладки**: вдоль, поперёк, смешанный — с переключением вкладок и метриками.
- 🖼 **3D и 2D виды**: трёхмерная сцена Three.js (@react-three/fiber, @react-three/drei) с прозрачным кузовом и тултипами, а также 2D-вид сверху с разрезами по слоям.
- 🖐 **Ручное редактирование**: перетаскивание грузов мышью в 2D (с учётом опор и коллизий), правка координат и поворота, перемещение грузов между слоями вверх/вниз.
- 📄 **Отчёты**: PDF с параметрами авто, списком грузов (сгруппированным по слоям), 2D-схемами и инструкцией для грузчиков; экспорт 3D-сцены в PNG; экспорт в Excel.
- 💡 **Подсказки по загрузке**: автоматические подсказки (баланс, габариты, штабелирование), обновляются после ручных правок.
- 💾 **Сохранение**: все данные (пресеты, грузы, раскладки, сессии) хранятся в localStorage.
- 🌗 **Тёмная/светлая тема**.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на **http://localhost:5173** (порт Vite по умолчанию).

## Сборка для продакшена

```bash
npm run build
npm run preview
```

Готовый статический бандл появится в папке `dist/` — его можно разместить на любом статическом хостинге (Netlify, Vercel, GitHub Pages).

## Структура проекта

```
src/
├── components/
│   ├── Layout/           # Header, Footer
│   ├── VehicleSelector/  # выбор и создание авто
│   ├── CargoTable/       # таблица грузов + CSV
│   ├── VariantTabs/      # вкладки вариантов
│   ├── MetricsPanel/     # карточки метрик
│   ├── Scene3D/          # 3D-сцена, контейнер, грузы, drag-контролы, редактор координат
│   ├── Report/           # кнопка отчёта
│   └── Settings/         # модалки настроек и сессий, переключатель темы
├── store/                # Zustand store
├── lib/
│   ├── packer/           # алгоритм упаковки, пресеты, типы
│   ├── export/           # PDF и PNG экспорт
│   └── csv/              # импорт/экспорт CSV
├── types/                # общие типы
└── utils/                # помощники
```
