# 🚛 CargoPlanner — 3D Планировщик загрузки автомобилей

CargoPlanner — автономное веб-приложение (SPA) для планирования загрузки грузовых автомобилей: бинпакинг, 3D/2D визуализация, подбор кузова и экспорт отчётов. Предназначен для логистов, диспетчеров и всех, кто ежедневно отвечает на вопрос: **как разместить груз в кузове максимально компактно и безопасно**.

Весь расчёт происходит в браузере: данные не покидают устройство.

---

## ✨ Основные возможности

- 🧊 **3D-визуализация** — интерактивная сцена на Three.js: вращение, зум, прозрачный кузов, тултипы с параметрами груза.
- 🗺 **2D-вид сверху** — послойные схемы с разрезами, перетаскивание и редактирование раскладки мышью.
- 🧩 **Три режима раскладки** — **Вдоль**, **Поперёк** и **Смешанный**; для каждой позиции рассчитываются метрики, а оптимальный вариант можно выбрать автоматически.
- 📚 **Штабелирование** — ручное и автоматическое, с проверкой опоры снизу, предельной высоты штабеля и высоты кузова.
- 🛢 **Цилиндрические грузы** — бочки, рулоны и трубы упаковываются в одной раскладке с прямоугольными грузами; настраивается ориентация (вертикально/горизонтально) и способ укладки (штабелирование / рядом).
- 📐 **Настраиваемые зазоры** — три независимых типа: **от стен** кузова, **между рядами по ширине** и **между рядами по длине**; зазоры уменьшают доступное пространство (учёт «пальца», прокладок и обрешётки) и учитываются во всех раскладках и экспортах.
- 🎯 **Умный подбор автомобиля** — автоматический перебор пресетов с детальной статистикой: количество груза, % веса, объём, габариты, возможность штабелирования и компактность раскладки.
- 🚚 **Каталог автомобилей** — готовые пресеты (ГАЗель, Бычок, ЗИЛ, КамАЗ, Фура) + собственные кузова с произвольными размерами.
- 📦 **Редактор грузов** — таблица с добавлением/удалением, пресеты (европаллет, финпаллет, бочки), CSV-импорт и экспорт, проверка веса и габаритов.
- 🌐 **Полная локализация** — русский и английский интерфейс, переключение единиц: **мм / см / м** и **кг / т**.
- 📄 **Экспорт отчётов** — **PDF** (параметры авто, метрики, зазоры, список грузов по слоям, 2D-схемы, инструкция для грузчиков), **PNG** (снимок 3D-сцены с метриками и зазорами) и **Excel** (параметры, грузы, зазоры, все варианты раскладки).
- 💡 **Подсказки по загрузке** — автоматические предупреждения (баланс, габариты, штабелирование), обновляются после ручных правок.
- 💾 **Сохранение состояния** — настройки, пресеты, грузы и раскладки сохраняются в браузере (localStorage); тёмная и светлая темы.

## 🚀 Установка и запуск

```bash
git clone https://github.com/managertlkgroup-hub/CargoPlanner.git
cd CargoPlanner
npm install
```

Запуск в режиме разработки:

```bash
npm run dev
```

Приложение откроется на **http://localhost:5173** (порт Vite по умолчанию).

Сборка для продакшена:

```bash
npm run build
npm run preview
```

Готовый статический бандл появится в папке `dist/` — его можно разместить на любом статическом хостинге (Netlify, Vercel, GitHub Pages).

| --- | --- |

## 🗂 Структура проекта

```
src/
├── components/
│   ├── Layout/           # Header (меню, экспорт), Footer
│   ├── VehicleSelector/  # выбор авто, пресеты, умный подбор (VehicleMatcher)
│   ├── CargoTable/       # таблица грузов, форма добавления, CSV
│   ├── VariantTabs/      # вкладки режимов раскладки (вдоль/поперёк/смешанный)
│   ├── MetricsPanel/     # карточки метрик
│   ├── Scene3D/          # 3D-сцена, контейнер, грузы, тултипы, drag-контролы
│   ├── Scene2D/          # 2D-вид сверху, ручное редактирование раскладки
│   ├── Report/           # PDF-отчёт и кнопки экспорта
│   ├── PresetDetails/    # детальная панель авто и груза
│   └── Settings/         # настройки, пресеты, сессии, тема
├── store/                # Zustand store (+миграции настроек)
├── lib/
│   ├── packer/           # алгоритм бинпакинга (зазоры, цилиндры, штабелирование)
│   ├── export/           # PDF, PNG, Excel экспорт
│   └── csv/              # импорт/экспорт CSV
├── types/                # общие типы
└── utils/                # helpers: единицы измерения, форматирование
```
